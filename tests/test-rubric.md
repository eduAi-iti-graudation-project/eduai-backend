# Argumentative Essay — Grading Rubric

**Grade 10 English Language Arts**
**Total Points: 50**

---

## 1. Thesis Statement — 10 points

| Score | Description |
|-------|-------------|
| 10–8 | Clear, specific, arguable thesis that directly addresses the prompt and outlines the essay's main points |
| 7–5 | Thesis is present but vague or only partially addresses the prompt |
| 4–1 | Thesis is missing, unclear, or merely restates the prompt |
| 0 | No thesis statement |

## 2. Evidence and Support — 15 points

| Score | Description |
|-------|-------------|
| 15–12 | Strong, relevant evidence from credible sources. Multiple pieces of evidence per claim. Sources are properly cited |
| 11–7 | Adequate evidence but may lack relevance or sufficient quantity. Some citations present |
| 6–1 | Minimal or irrelevant evidence. Few or no citations |
| 0 | No evidence provided |

## 3. Organization and Structure — 10 points

| Score | Description |
|-------|-------------|
| 10–8 | Logical progression of ideas with clear introduction, body paragraphs, and conclusion. Effective transitions |
| 7–5 | Generally organized but some paragraphs lack focus or transitions are weak |
| 4–1 | Poor organization. Ideas jump between paragraphs. Missing introduction or conclusion |
| 0 | No discernible structure |

## 4. Grammar and Mechanics — 5 points

| Score | Description |
|-------|-------------|
| 5–4 | Few to no grammatical errors. Proper punctuation, spelling, and sentence structure |
| 3–2 | Some errors but they do not significantly impede understanding |
| 1 | Frequent errors that distract from the content |
| 0 | Incomprehensible due to errors |

## 5. Conclusion — 5 points

| Score | Description |
|-------|-------------|
| 5–4 | Strong conclusion that restates thesis, summarizes key points, and leaves a lasting impression |
| 3–2 | Conclusion restates thesis but adds little new insight |
| 1 | Conclusion is weak, repetitive, or unrelated to the essay |
| 0 | No conclusion |

## 6. Counterargument and Rebuttal — 5 points

| Score | Description |
|-------|-------------|
| 5–4 | Acknowledges opposing views and provides effective rebuttal |
| 3–2 | Mentions counterargument but rebuttal is weak or incomplete |
| 1 | Counterargument is missing or poorly addressed |
| 0 | No attempt to address opposing views |
