# Argumentative Essay Rubric

## Thesis Statement (10 points)
The essay presents a clear, specific, and arguable thesis statement that directly addresses the prompt.

| Score | Description |
|-------|-------------|
| 9-10  | Exceptionally clear, specific, and compelling thesis that previews the argument |
| 7-8   | Clear thesis that addresses the prompt but could be more specific |
| 5-6   | Thesis is present but vague or unfocused |
| 3-4   | Thesis is unclear or does not directly address the prompt |
| 0-2   | No identifiable thesis statement |

## Evidence and Support (15 points)
Arguments are supported with relevant, credible evidence including examples, data, and citations.

| Score  | Description |
|--------|-------------|
| 13-15  | Strong, varied evidence from multiple sources; all claims well-supported |
| 10-12  | Good evidence supporting most claims; minor gaps |
| 7-9    | Some evidence provided but insufficient or not fully relevant |
| 4-6    | Minimal evidence; claims largely unsupported |
| 0-3    | No evidence provided; purely opinion-based |

## Counterargument and Rebuttal (10 points)
Acknowledges opposing viewpoints and provides thoughtful rebuttal.

| Score | Description |
|-------|-------------|
| 9-10  | Excellent recognition of opposing views with strong, logical rebuttal |
| 7-8   | Good counterargument presented but rebuttal could be stronger |
| 5-6   | Counterargument mentioned but not fully developed or rebutted |
| 3-4   | Weak or superficial counterargument; no real rebuttal |
| 0-2   | No counterargument addressed |

## Organization and Structure (10 points)
Ideas flow logically with clear introduction, body paragraphs, and conclusion.

| Score | Description |
|-------|-------------|
| 9-10  | Exemplary structure; each paragraph flows naturally to the next |
| 7-8   | Good organization with clear paragraphs and transitions |
| 5-6   | Adequate structure but some paragraphs lack focus or transitions |
| 3-4   | Poor organization; ideas are disjointed |
| 0-2   | No discernible structure; chaotic presentation |

## Grammar and Mechanics (5 points)
Writing is free of grammatical errors with proper punctuation, spelling, and sentence structure.

| Score | Description |
|-------|-------------|
| 5     | Virtually error-free; sophisticated sentence variety |
| 4     | Minor errors that do not impede readability |
| 3     | Several errors that occasionally distract |
| 2     | Frequent errors that impede readability |
| 0-1   | Pervasive errors making the essay difficult to read |

---

**Total Points: 50**
